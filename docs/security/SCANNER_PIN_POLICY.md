# Politique de versions des scanners

Versions vérifiées depuis le 4 août 2026 : Opengrep 1.22.0, Trivy 0.70.0, Gitleaks 8.30.1 et zizmor 1.26.1. zizmor fonctionne avec `--offline`. L’installation Windows partagée se fait une seule fois depuis SpaceShooter ou MailPerch, puis `tools/security/security-scan.ps1` peut être lancé dans ce dépôt.
