## Users

Discord desktop users. The owner prioritizes reading, long discussions and voice conversations, as confirmed on 24 October 2026.

## Product Purpose

Sibylla is the main installable CSS theme for Discord, with North Polar, North Snow, Spatial and Tokyo-night flavors. It changes presentation while preserving Discord's navigation, content, commands and interaction semantics.

## Operating Context

The current validation environment is Discord desktop Linux 1.0.166 with Vencord in a dedicated VPS laboratory. The owner's personal Windows Discord is outside this validation pass. Theme Lab provides demonstration messages for private visual validation. Real client observations and synthetic CSS checks are recorded separately.

## Capabilities and Constraints

- Build five standalone versions from the approved North Polar composition. The old nine variants are retired from active sources; Git history retains their provenance.
- Preserve unread/mention indicators, native voice controls, keyboard focus, reduced motion and custom profile semantics.
- Preserve the current call and draft during read-only visual inspection. Sending messages or changing calls requires a specific authorized test.
- No new runtime remote resources, scripts or telemetry. The existing Figtree font import is retained. Eleven reviewed Lucide SVGs (ten active masks) are vendored locally with their license and pinned provenance; no icon JavaScript runs in Discord.
- Camera is unavailable in the current client; BetterDiscord runtime and Windows accessibility modes are not validated here.

## Product Principles

- Sustained reading and voice use lead visual decisions.
- Native functions remain immediately recognizable.
- State and hierarchy must remain clear without relying only on color.
- The redesign must be visibly comprehensive, rather than described as a redesign after only local fixes.
- Validation reports distinguish rendered evidence from source analysis and synthetic checks.
- Base Discord functions must stay visible and reachable. Record read-only checks per function and distinguish unavailable or unexecuted operations; do not claim every Discord feature works from screenshots alone.

## Visual exclusions

The owner explicitly rejects generic AI-generated visual defaults. The approved references govern composition: continuous reading canvas, restrained Nord surface hierarchy, measured spacing, one composer surface and a clearly integrated account area. Avoid decorative cards inside cards, blanket rounded panels, glow, glass blur, gradients used as decoration, excessive badges, gratuitous motion and improvised ambiguous icons. Native Discord content, status and accessible controls remain authoritative. Passing static checks alone never validates the visual direction.
