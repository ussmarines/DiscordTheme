# Repository banner

`repository-banner.jpg` is the 1280 × 640 GitHub/README banner. It uses the owner-provided transparent Sibylla emblem, the established midnight/gold palette, Figtree typography and the five theme palettes. It contains no account details or private Discord content.

Source: `repository-banner.html`. Render it at 1280 × 640 and capture after the font and emblem load. The browser exports JPEG; keep the real `.jpg` extension. The file is below GitHub's 1 MB social-preview limit.

The README image is versioned here. GitHub's separate social-preview setting requires uploading the file through repository Settings → General → Social preview.
