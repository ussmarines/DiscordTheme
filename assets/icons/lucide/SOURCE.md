# Lucide outline icons

Source: https://github.com/lucide-icons/lucide/tree/7faf87628a1ad6175975bc595344337ce14a7db4/icons

Commit: 7faf87628a1ad6175975bc595344337ce14a7db4

Eleven SVGs are included: the original five header/home icons and signal, video, video-off, screen-share, shapes and party-popper for the voice dock. Original files are retained unchanged; build-time masks use their geometry. No JavaScript package or remote runtime icon resource is loaded. License is included alongside the SVGs.

The signal SVG is retained as a reference asset but is no longer emitted into the active CSS: Discord owns the quality-level geometry and opacity. The active icon family contains ten masks; the native quality indicator is 16px without extra padding.
