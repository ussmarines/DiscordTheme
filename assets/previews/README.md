# Public theme previews

The five 1600 × 1000 PNG files are browser-rendered illustrations made from the actual current theme CSS by `scripts/previews.js`. Server names, members, avatar initials, times and messages are authored fictional data. No Discord profile, server, message, screenshot or personal media was accessed to create them. The approved supplied Sibylla logo and space background are theme assets, not personal account artwork.

Each image is explicitly labeled as synthetic. These images illustrate palettes and shared composition; they are not native Discord compatibility evidence. The preview-only host scaffold and illustrative controls are not included in installed themes.

Regenerate HTML with `node scripts/previews.js`, then capture each generated page in a browser at 1600 × 1000 after fonts load. Keep identical framing and content across all five. Never replace these with private account captures.
